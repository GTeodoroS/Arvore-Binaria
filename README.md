Projeto da disciplina de Resolução de Problemas Estruturados em Computação

O objetivo era fazer uma estrutura de dados de árvore, e com isso ser capaz de traduzir código morse

O código é divido em 3 Classe:

1. Nodo, onde será inicializado um nó novo, basicamente consiste no construtor e em atributos públicos para facilitar a comunicação interna.
2. ArvoreBinaria,  onde está localizado o construtor da árvore e os métodos inserir e buscar.
3. Main, onde o construtor da arvore é inicializado, e inserido todos os dados da árvore Morse automaticamente, além de ser onde se realiza a busca.

Para realizar a decodificação de um codigo em binario para seu texto original, deve-se escrever na Classe Main arvore.buscar("[texto em morse]"),
utilizando espaço " " para separar cada letra, e uma barra "/" para separar cada palavra.
